# Discord_Game_Bot

一個用 **Python** 撰寫的 Discord Bot，提供簡單的文字互動小遊戲。

此專案為 **馬公高中 陳昊宇 - 學生自主學習計畫：以Python撰寫Discord Bot** 的成果。

---

## 功能

Bot 內建四款小遊戲：

- **1A2B**
- **圈圈叉叉**
- **終極密碼**
- **猜拳**

---

## 安裝與使用

1. 安裝需求
    - Python 3.8+
    - `discord.py`
2. 安裝套件
    
    ```bash
    pip install -r requirements.txt
    
    ```
    
3. 在 `Setting.json` 填入 Bot Token：
    
    ```json
    {
      "TOKEN": "YOUR_BOT_TOKEN"
    }
    
    ```
    
4. 啟動 Bot
    
    ```bash
    python bot.py
    
    ```
